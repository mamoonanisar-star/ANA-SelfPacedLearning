Motivation

▸
Problem

ANA slides are large; split into ~20 patches (448×448). ResNet-50 baseline collapses each patch to a single global vector — discarding all spatial structure.

▸
Hypothesis

CLIP ViT produces 257 token embeddings per patch (1 CLS + 16×16 spatial). These preserve spatial structure and enable richer SPL suppression decisions.

▸
Goal

Replace ResNet-50 features with token sequences and add a Region Confidence Estimator to guide the SPL framework.

TokenAttentionPooling detail:

q = W_q(CLS)            # [B,1,H]
k = W_k(tokens)         # [B,T,H]
a = softmax(q·kᵀ/√H)   # [B,1,T]
z = a·tokens            # [B,768]

Token-Weighted SPL Loss

Combines learned SPL instance weights with the per-patch region confidence:

w̃i = relu(wi) × (1 + α · confidencei)
𝓛 = Σi,c: y=1 BCE(pic, yic) × w̃ic
SymbolMeaning
wiLearned SPL weight (self-paced learning)
confidenceiPer-patch score from RegionConfidenceEstimator
αConfidence contribution (default 0.5)
α = 0Reduces exactly to baseline WeightedBCELoss

SPL Weight Initialisation Strategies:

StrategyBehaviour
iw-onesAll weights = 1 (uniform)
iw-dataProportional to label distribution
iw-sampleGrouped by parent image (recommended)

Data Pipeline

1
Large ANA Slide

High-res fluorescence microscopy image (patient slide).

2
Instance Sampler (get_small())

Splits each slide into ~20 non-overlapping 448×448 sub-region patches. These become rows in the CSV annotation file.

3
CLIP Token Extraction (extract_clip_tokens.py)

Loads CLIP ViT, hooks the last transformer block to get full token sequence (not just pooled CLS). Saves [257, 768] arrays as .npy files.

4
ANATokenDataset (data_clip_tokens.py)

Loads .npy files at training time. Supports flat & hierarchical layouts. Falls back to zero tensor on missing files.

5
Training + Evaluation (main_with_tokens.py)

Self-paced learning loop with adaptive weight updates. Saves best model checkpoints for mAP, F1-mi, F1-ma, Accuracy.

6
Analysis (analyze_tokens.py)

Visualises token attention heatmaps, patch suppression distribution, confidence histograms, and benchmark comparison tables.

Run Locally — Step by Step

1
Install dependencies 
pip install -r requirements.txt
# CLIP (pick one):
pip install git+https://github.com/openai/CLIP.git
# OR:
pip install open-clip-torch
2
Prepare data structure 
data/
├── images/          # raw ANA patch images
│   ├── 0001.jpg
│   └── ...
└── clip_tokens/     # created by step 3
3
Extract CLIP tokens (one-time) 
python extract_clip_tokens.py \
  --annFile all_single_small_82240_19400_19330.csv \
  --img_root ./data/images/ \
  --out_dir  ./data/clip_tokens/ \
  --model    ViT-L/14
4
Update config.py paths 
DIR_TRAIN_IMAGES = './data/images/'
PATH_TRAIN_ANNFILE = 'your_annotations.csv'
TOKENS_ROOT = './data/clip_tokens/'
5
Train token model 
python main_with_tokens.py \
  --use_tokens \
  --tokens_root ./data/clip_tokens/ \
  --num_tokens 257 --token_dim 768 \
  --saveModel --lr 1e-3 --weight_lr 1e-3 \
  --initWeight iw-sample \
  --updateLR ulr-adaptive \
  --granularity label \
  --sampling \
  --trainingLabel pseudo
6
Analyse & visualise 
python analyze_tokens.py \
  --model_path ./token_*/best_f1ma.pt \
  --tokens_root ./data/clip_tokens/ \
  --annFile all_single_small_82240_19400_19330.csv \
  --out_dir ./analysis_output/
